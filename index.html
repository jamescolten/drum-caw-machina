      Where the sounds come from
      
No recordings or sample packs. Every sound is generated live in your browser with the Web Audio API that's built into the browser, then run through light saturation for a lo-fi edge. The sounds were designed from general sound-synthesis know-how, not copied from one page. Each [About] link is a reference: for drums, an article explaining the same technique; for birds, real recordings of that bird to compare against.
